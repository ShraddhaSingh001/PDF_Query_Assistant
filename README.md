# PDF Quest — PDF Query Assistant
A web-based application that allows users to upload PDF documents and ask questions about their content using AI.

# Features
- Upload PDFs and extract text.
- Ask questions about document content.
- Generate answers using AI APIs.
- Switch between supported AI model providers.

# Technologies Used
HTML, CSS, JavaScript, and APIs (Groq, OpenAI, or GitHub Models).

# How It Works
The app reads text from uploaded PDFs, processes user questions, and uses the selected API model to generate answers based on the document content.

# How to Run
1. Clone this repository.
2. Open the project using a local development server.
3. Configure the required API credentials.
4. Upload a PDF and ask questions.
